# Launch checklist

- [ ] Set `NEXT_PUBLIC_SITE_URL` to the verified production domain.
- [ ] Provide verified phone, WhatsApp, and enquiry email values.
- [ ] Configure and test the server-only `LEAD_WEBHOOK_URL`.
- [ ] Choose and implement the required analytics-consent approach before adding analytics IDs.
- [ ] Verify Google Search Console and set its token.
- [ ] Add approved project imagery and OG artwork.
- [ ] Complete official legal review of Privacy and Disclaimer pages.
- [ ] Run `npm install`, `npm run typecheck`, `npm run lint`, and `npm run build`.
- [ ] Perform device/browser, keyboard, form delivery, and production SEO validation.
